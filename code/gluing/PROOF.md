# Joining arbitrary Boolean pieces by certified translations

## Replay and scope of the source claims

The supplied Three_Actors_Proofs_and_Experiments.zip was extracted into a new temporary directory. Running python3 -B verify.py --full --jobs 2 regenerated all 18 recorded experiment outputs. The report in SOURCE_REPLAY.json records individual script and reference digests. This is a replay of the released programs. The independent logic below can also be checked without those programs.

Write F,G,H,I for pieces, and f,g,h,i for their satisfiability. With A = f AND g, B = f AND h and C = g AND i, exactly seven of the eight masks occur. The missing mask is 6, with B and C viable and A impossible (bit weights 1,2,4). B and C supply witnesses for F and G. For A these witnesses can be combined when its pieces have disjoint private variables and compatible boundary values. Among the six allowed nonzero masks, each binary projection takes all four values. Revealing a pair's true statuses on a particular input is a different information contract from inferring which pair statuses can occur across the family.

The released simple gluing test recognizes disjoint pieces. The second test uses a complement symmetry to align a single common variable. Each suite generated 16 status combinations and a matched seventeenth control. In the control the F copy in B was replaced, mask 6 became true, and the reader abstained. The connected tests used 11,645 vertices and 21,060 edges per graph. Private pieces in these finite examples were produced from binary clauses. The logical implication allows arbitrary SAT payloads, provided their component identities and the gluing property are certified.

**Seven-source reduction.** Label seven SAT completion questions 1 to 7. For query bit b compile the OR of labels with bit b set. The three questions, encoded at the designated star, return the bitwise OR of all viable labels. With one viable label, a false nonzero answer names a dead label. With two or more, deleting any one label leaves a viable one. With none, the correctness invariant imposes no restriction. The actor must run within a uniform polynomial bound even when there is no viable label. An invalid return on such an input can be replaced by a fixed syntactically valid label. Split surviving prefixes by one input variable, delete until at most six remain, and check the remaining assignments individually at the end. This costs polynomial time because each round starts with at most twelve prefixes. The reduction promises neither a unique satisfying assignment nor success against an unbounded solver. Conversely a polynomial SAT decider computes the three bits and excludes any other nonzero mask. This is a concrete membership-comparability reduction; that paradigm is classical. [Ogihara, Polynomial-Time Membership Comparable Sets](https://doi.org/10.1137/S0097539793258131)

## Interface quotient for overlapping pieces

Let F and G be Boolean constraint systems with exactly the k boundary variables in common. A solution of F supplies a boundary vector x in V = GF(2)^k; write S for the set of such vectors, and T for G's corresponding set. Let U,V' be certified translation subspaces such that S+U=S and T+V'=T. A sufficient certificate for any translation is a simultaneous bit flip of all appropriate variables in a piece that takes every solution to another solution. Define W=U+V', let π be the map to the quotient Q=V/W, and let δ=k−dim(W).

**Theorem.** F and G have a common completion exactly if π(S) and π(T) intersect. Given an original F witness with boundary x and a G witness with boundary y in the same quotient class, and lifts of the basis flips to all local variables, the witnesses can be aligned in polynomial time.

*Proof.* A shared boundary plainly gives a common class. In the other direction choose x in S and y in T with equal classes. Then x+y=u+v for some u in U and v in V'. Thus x+u=y+v belongs to both boundary supports. Solve for the coefficients of u and v by binary elimination. When certified full-space lifts were given, applying the corresponding flips to the original witnesses constructs compatible witnesses. Private variables can then be united. This is a quotient of finite-dimensional vector spaces, independent of the difficulty of obtaining the original witnesses.

**Zero residual dimension.** If δ=0 then any separate witnesses can be joined. Consequently the original implication B AND C implies A also holds when A's pieces share arbitrarily many bits, provided the rank certificate applies and their individual satisfiability follows from B and C. The conclusion concerns decoded formulas and an identified decomposition; a universal recognition algorithm on raw seven-source compiler graphs has not been established.

**How the actor gets sound flip spaces.** For a bounded-width CNF, group clauses by identical variable scope. Enumerate the allowed local bit relation R on each scope. Its shifts z with R+z=R form a linear subspace K (the subgroup of translations preserving R). At fixed width both K and its orthogonal equations can be computed from the local table in constant time per group apart from bookkeeping. Lift the homogeneous equations to all variables in the piece. Their common kernel consists of bit flips stabilizing every scope relation, and therefore preserves the full solution set. Project its basis to the shared variables, retaining the full basis as lifts. This procedure is polynomial in the input length even with unbounded k. Larger semantic symmetry groups can exist. The test requires only certified subspaces, and needs no oracle for their maximality.

**Optimality for arbitrary future supports.** If one piece can send just one message before learning the other piece's support, the complete future-intersection test for arbitrary support sets may require 2^δ bits. Storing the characteristic vector of π(S) achieves this bound. Conversely the left piece can have S=π⁻¹(L) for any L⊆Q, and the right piece can query π⁻¹({q}) for any q∈Q. Distinct L then require distinct messages. With fixed-length messages or worst-case prefix-free encodings the bound follows by counting. This unrestricted-support lower bound includes empty supports and concerns communication rather than time to compute supports. Prescribed certified groups act on all inputs to this argument, even if some specific support admits extra symmetries.

**Already one unresolved bit is hard.** Deciding joint satisfiability of two individually satisfiable width-three Boolean systems, with one shared bit and explicit separate witnesses, is NP-complete, even when neither side can translate the shared bit by a global solution-preserving XOR flip. Given any 3-CNF φ, introduce a deterministic Boolean gate circuit y=φ(x) with a unique gate-value extension for every x. Encode each gate with ordinary clauses of width at most three. Piece F adds (¬s OR t) and (¬s OR y); t is a fresh private bit. Piece G is the unit clause (s). An explicit F witness sets s=t=0 and x=0, evaluating the circuit. An explicit G witness sets s=1. Their join exists exactly if φ is satisfiable. In F, s=0 has 2^(|x|+1) witnesses because t is free, whereas s=1 has at most 2^|x| because t=1 and φ must hold. A translation that flips s would biject those slices and hence cannot exist. G fixes s outright. Thus the certified spaces project to zero, δ=1. Joint SAT is in NP, and the promised separate witnesses are computable within the reduction. Individual pieces may have larger symmetries of their boundary-support sets than those supplied by full-variable witness translations. This hardness result concerns joint completion; it does not itself show hardness of outputting a false pattern when two branch statuses are already known.

## General overlap diagrams

For systems indexed by i, use the independent occurrence space L = direct sum of local coordinate spaces. The subspace E identifies occurrences of the same original bit. Let H be the direct sum of global certified flip spaces in the individual pieces. Given individual witnesses with occurrence vector a, they can be made consistent using the certified flips exactly when a belongs to E+H. When E+H=L, every tuple of individual witnesses glues, for arbitrary cyclic overlap patterns. If E+H is proper, choose any a outside it. Relations with local solution sets a_i+H_i are individually satisfiable but incompatible globally. Thus surjectivity is necessary only for a guarantee based on the stated symmetries alone. This general statement is elementary linear algebra. No bibliographic priority is claimed. Foundational context for affine Boolean constraints is provided by [Schaefer's dichotomy theorem](https://doi.org/10.1145/800133.804350).

## Adversarial checks

Run python3 run.py and compare to RESULTS.json. The code enumerates the two-piece quotient theorem for every pair of binary subspaces in dimensions 1 through 3 and all unions of their cosets. This gives 159,340 comparisons across 285 subspace pairs. In a 64-bit interface, alternating equality pairs along an open path gave flip dimensions 32 and 33 whose sum spans all 64 boundary bits. Closing the path with one opposite-bit pair left a single unresolved parity, and the supplied two local witnesses then had inconsistent syndromes. The reader computed flip spaces from ordinary local clauses. The one-bit hardness control also tests all sixteen Boolean functions on two inputs. The seven-tag test checks all 128 live sets and all 769 in-contract output cases. The finite cases test the implementation. The proofs above establish the arbitrary-size statements.
