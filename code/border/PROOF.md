# Exact and formal-border projection audit

## Source and archive

The November 23 version 1 of *VP ≠ VNP over every field* states its approximation claim as Theorem 1.4. Its definition allows constants in K((ε)), the Laurent series field. The final output must be F+εR, with R a polynomial in the ordinary circuit variables and coefficients in K[[ε]]. Negative ε-powers can occur at intermediate gates. The paper counts both inputs and arithmetic gates. Anthropic supplies a Lean development and describes the initial paper as human-unreviewed. This audit inspected the statement and the project reduction and did not rebuild Lean. ## Gate-by-gate transfer

Let P_H(z) sum, over all valid binary colorings, the product of variables z_v for vertices v with bit one. The earlier physical projection φ sends each z_v to 0, 1, or one input-arc variable x_e. There is a single phase per logical Boolean variable, fixed along its equality ring. The Boolean verifier for an arc set has a unique gate assignment, and accepts precisely directed Hamiltonian cycles. Every physical piece has a nonconstant private row with six options. Setting its first two private positive weights to zero forces the unique private word 001. Setting one positive reference port to zero fixes the orientation. Every accepted arc set then contributes its own monomial exactly once. This proves φ(P_H)=HC as a formal polynomial identity over the integers. It therefore survives every field specialization, including characteristics two and three.

**Corollary, conditional on the external Theorem 1.4.** For the explicit family H_m of the earlier construction, the ordinary one-weight-per-vertex coloring polynomial requires more than m^{c(log₂ m)^{1/3}} gates even for formal border approximation over any field, for m sufficiently large at that characteristic. In terms of its physical vertex count V_m=poly(m) this is exp(Ω((log V_m)^{4/3})) along the family. The constant-transfer statement in m uses the external theorem's constant.

**Proof.** Extend φ coefficientwise, fixing ε and the field constants. If an L-gate circuit computes P_H+εR over the Laurent series field, relabel every input by its image under φ. Every image is a single permitted constant or variable, so the circuit still has at most L gates even in a size convention that counts its input leaves. The new output is HC+εφ(R). Its error remains regular since φ(R) has power-series coefficients. Thus the circuit border-approximates HC and Theorem 1.4 applies. This argument is projection monotonicity of border complexity. It does not bound additive or relative numerical approximation at selected real arguments, randomized Boolean witness-finding, or the seven-tag actor.

## A nonzero symbolic weight gives the same limit

Here is an exact control that also describes the discarded terms. Write B for the number of nine-point pieces and E for the arcs of the complete loopless directed graph. Change every zero vertex weight in the projection to a common new variable t, leaving all other weights fixed at 1 or x_e. The coloring polynomial after this specialization is exactly

    (1 + 4t + t²)^B · [ HC_m(x) + t · Σ_C ∏_{e∈E minus C} x_e ].

The sum inside the bracket runs over all directed Hamiltonian cycles C, each taken once up to cyclic rotation. The six valid private words, in order 001, 010, 011, 100, 101, 110, contribute 1,t,t,t,t,t². This factor is identical for either phase and independent across B pieces. In reference phase zero the surviving input words are exactly the cycle incidence words. The complement bijection gives the entire set of input words in reference phase one, and the weighted reference port contributes t on that sector. This proves the formula with integer coefficients. Its constant term is HC over every field. The identity is an explicit deformation of the earlier construction and requires no external lower bound.

Choosing t=ε in this formula uses only nonzero input weights 1, ε and edge indeterminates, and makes the output HC+O(ε) in the formal coefficientwise sense. This also works when composing an already approximate circuit with the same substitution. Its input images have no negative ε-powers, so regular error remains regular. The restriction on input images matters: substituting ε⁻¹ for z in the error εz turns it into one. At the opposite ordinary specialization t=1, the private coefficient is 6^B; in characteristics two and three this annihilates the whole expression although H contains valid colorings. Thus one arbitrary field evaluation cannot decide existence.

## Finite replay

Run python3 -B run.py and compare its stdout with RESULTS.json. The standalone program constructs the local punctured affine plane independently, tests 512 local words, obtains coefficients (1,4,1) in each reference phase and checks the exact cycle/complement support for m=2,3,4. It implements an exact Laurent-polynomial circuit on the physical nine-point chart whose intermediate gate values have negative ε-powers that cancel. Its output after projection recovers x+y as the constant term over the integers and modulo 2,3,5,7, including tested terms killed or merged by the projection. These tests complement the archived full hypergraph checks. The all-field statement relies on the algebraic proof.
