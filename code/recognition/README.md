# Exact recognition of 5V/12 attainment

Deterministic polynomial-time algorithm that decides whether a linear four-matching system attains the sharp bound, constructs an extremal flat when one exists, and counts the distinct extremal flats.

Based on footprint exact cover with at most three candidate footprints per triple, plus constant-size exhaustion of the 64-row case.

See the full implementation and proofs in the Safe_Forgetting_Research_and_Replay archive.
